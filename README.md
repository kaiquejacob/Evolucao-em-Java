## `SOBRE`

Repositório estruturado para documentar minha evolução no ecossistema **Java Back-End**, cobrindo desde os fundamentos da linguagem até arquitetura de software, padrões de projeto, persistência de dados e microsserviços com **Spring Boot**.

A organização segue uma estrutura modular dividida por pilares conceituais. Cada módulo possui documentação técnica própria (`README.md`) e testes automatizados.

---

```text
JAVA EVOLUTION

[✓] 01. Java Fundamentos
    ├── Fundamentos básicos, estruturas e arrays
    ├── Orientação a Objetos (Herança, Polimorfismo, Abstração, Interfaces)
    ├── Classes utilitárias (Datas, IO/NIO, Regex, Serialização)

    └── Classes internas (Inner, Local, Anônima, Estática)

    ├── Coleções (List, Set, Map, Queue) e Generics
    ├── Programação funcional (Lambdas, Method Reference, Optional)
    ├── Streams API e Concorrência (Threads, Concurrent collections)
    └── Annotation Processing (Metaprogramação em build-time)

[✓] 03. Persistência e Dados
    └── JDBC puro (PreparedStatement, Transactions, Connection Leak)

[✓] 04. Arquitetura e Boas Práticas
    ├── Princípios SOLID e Clean Code
    └── Design Patterns GoF (Singleton, Strategy, Facade, Builder, Factory, DTO)

[✓] 05. Ecossistema Spring
    ├── Spring Web REST API (Clean Architecture, Controllers, DTOs)

    └── Spring Cloud OpenFeign (Integrações HTTP declarativas, Fallback)
```
